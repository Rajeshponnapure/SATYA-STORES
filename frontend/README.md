# Frontend

The root [project README](../README.md) is the source of truth for architecture, features, routes, setup, environment variables, database configuration, and commands.

This application is a Next.js 15 App Router project using React, TypeScript, and Tailwind CSS.

## Local development

From this directory:

```powershell
npm install
npm run dev
```

The frontend runs at http://localhost:3000. Start the backend separately; see the root README.

## Commands

- `npm run lint` — run ESLint.
- `npm run build` — type-check and build production output.
- `npm start` — serve a production build.
